# 方案二下游的全量准备池（中间复现依赖）

本目录是2257条来源（2045条外部＋212条EqGPT非目标）的原LaTeX/GRE配对准备池，包含72224条增强样本和初筛词表。它不是第三套正式实验，也不是实际完成训练所使用的80容量子集。

`prepare_expanded_downstream_80.py`使用这里的词表做第一次80长度筛选，随后只用保留源公式重新训练词表和复核，因此保留此目录用于完整重建。实际训练输入在 `../expanded_downstream_80_v1/`（1855条、59360样本）。`PROPOSED_PROTOCOL.json`和审计描述的是准备阶段，最终设置以80子集中的 `APPROVED_PROTOCOL.json`为准。
