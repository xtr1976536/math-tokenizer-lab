# Editable Beamer master

Run `latexmk -xelatex mathematical_tokenizer.tex` from this folder. Requires XeLaTeX, Beamer and ctex. The source and template remain editable; assets are vector PDF data figures. The cover information and October 10, 2026 date are preserved from the reference at user request; the research was updated October 13, 2026.

The accompanying PowerPoint contains exact high-resolution renderings, with source text in notes. Edit the TeX master to change content.
