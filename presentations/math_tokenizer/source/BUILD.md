# Editable Beamer master

Compile with `latexmk -xelatex -outdir=../build mathematical_tokenizer.tex`.
Requires XeLaTeX, Beamer, ctex and Apple Symbols for the SentencePiece space glyph.
30 pages; cover identity/date retained. Only used references are listed,with
numeric internal hyperlinks. Dataset source pipeline is an embedded drawio PDF.

PowerPoint pages preserve Beamer image typography and carry native hyperlink
hotspots. Edit this TeX master andexport with scripts/export_presentation.py.
