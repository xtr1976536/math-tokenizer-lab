# Current seven-system intrinsic evidence

`registry.json` records 19 frozen configurations from the two routes and five selected baselines. `metrics.json` has 109 metric records; `per_formula.jsonl.gz` contains 234,556 formula-result rows. The same seven suites are retained where applicable: final v8 new-paper / extreme, exposed v7/v6 natural / extreme, and stress. Specialized models evaluate only domain-eligible and stress suites.

These are byte-identical model copies and an unchanged subset of the v8 experiment at commit 5217a5a. The seven-system restriction is retrospective, so its composite ranking is not the original all-method ranking. `frozen_provenance.json` preserves the original model-freeze timestamp; `paired_effects.json` retains the selected pair and the original comparison-family size. Complete older comparisons remain only in history. Original 144-family adjusted intervals are retained, not recalculated with a smaller comparison count.

Run `scripts/audit_current.py` for three actual audits: whole-catalog provenance/classification; all public-encoder/payload/metric replays; independent paper/count aggregation, calibration and timing checks. `three_round_audit.json` records the checks and hashes. `rankings.json` and `metrics.csv` are generated by `summarize_current.py` only after audit success.

Timing uses seven interleaved full public-interface runs from the frozen experiment. Reorganization does not invent new speed measurements. General tokenizers retain their actual full ID spaces. Fit probability calibration uses the same IDs for the appropriate scenario; no formula is truncated or filtered for one model.
