# 三套实验方案与仓库边界

本仓库正式保留三套并列的下游 PDE 发现实验。实验一和实验二同时包含上游分词评估；实验三专门研究大小语料对下游发现的影响。不同方案不覆盖，实验结果不因本次整理而重新训练或修改。

## 三个下游实验的设计差异

| 设计维度 | 实验一：原 benchmark | 实验二：扩大语料 | 实验三：语料规模效应 |
|---|---|---|---|
| 研究目的 | 建立原始下游基线，并比较三类 Hard 容量 | 在独立上游 8:1:1 方案后评估扩大语料版本 | 配对比较小/大语料对生成与选择的影响 |
| 训练源公式 | 每个目标排除后的 212 条原 EqGPT 公式 | 212 条原公式 + 1,643 条外部公式 = 1,855 条 | 小组 212 条；大组 212 条 + 888 条外部公式 = 1,100 条 |
| Hard 词表训练文本 | 旧版各案例词表流程 | 1,855 条未增强原始 LaTeX | 小、大组分别用各自未增强、统一 GRE 渲染 LaTeX 重学，词表不共享 |
| Transformer 输入 | 原实验增强序列 | 59,360 条，固定种子 32 条等价排列 | 小组 6,784 条；大组 35,200 条；两组均 32 条 |
| 增强与 EOS | 原作者排列增强，沿用原流程 | 固定种子采样等价排列，EOS 在句尾 | 只交换顶层加法项与标量乘法因子；EOS 严格在句尾 |
| 训练/搜索容量 | 50 token | 80 token | 60 token |
| 语料组关系 | 单一基线组 | 单一扩大组 | 小、大组均跑完整八案例，初始张量和搜索预算配对 |
| 机制记录 | 候选、reward 和 Top-10 结果 | 候选和搜索结果 | 额外追踪正确结构是否生成、是否可评分、是否被 Top-10 选择以及微调前后固定表达分数 |
| 代码、结果、权重 | [`experiments/downstream/`](../experiments/downstream/)、[结果](downstream/README.md) | [`experiments/expanded_downstream_80_v1/`](../experiments/expanded_downstream_80_v1/)、[结果](expanded_downstream_80_v1/report_zh.md) | [`experiments/study3_corpus_effect_v1/`](../experiments/study3_corpus_effect_v1/)、[配对报告](study3_corpus_effect_v1/study3_final_report_zh.md) |

三套实验均使用 EqGPT GRE、Hard AST-BPE 280/315/350、3 层 Transformer、25 epoch、seed 525、八案例、每案例每 arm 三轮×200 候选、每轮 2 epoch continuation，并只读复用同一批八案例 MLP 缓存；均未做最终 PINN 系数拟合。实验三的独立权重 Release、SHA-256 清单和下载脚本见 [Study 3 说明](../experiments/study3_corpus_effect_v1/README.md)。

|---|---|---|
| 上游代码 | `scripts/evaluate_screened_pde.py`、`scripts/analyze_pde_vocab_usage.py` | `scripts/run_upstream_811.py`、`scripts/audit_preparation.py` |

| 上游汇总 | [方案一说明](upstream/README.md)、`reports/vocab_usage/` | [方案二说明](preparation_811/README.md) |
| 下游代码 | `scripts/eqgpt/fast_reward_case.py` | `scripts/eqgpt/expanded_fast_reward_case.py`、`scripts/eqgpt/run_expanded_all_cases.py` |
| 下游原benchmark | `data/formulas/eqgpt/PDE_dataset_0725.xlsx`（221条）及 `augmented/<case>/`（212条、6784增强样本） | 新外部 `gre_benchmark_filtered/` 2045条＋原非目标212条；完整准备2257条，实际80共同子集1855条、59360样本 |
| 下游实际输入与词表 | `data/formulas/eqgpt/augmented/`；`experiments/downstream/<case>/tokenizers/` | `data/formulas/expanded_downstream_80_v1/`及其中 `tokenizers_round_0/` |

共享代码保存在 `src/`、`native/`；原作者实现与哈希见 `eqgpt_original/`。八案例观测数据 `data/cases/`、八份MLP `data/mlp_cache/`和通用分词器 `data/tokenizers/`供两套方案复用。初始公式池的来源与结构审计同样属于必要复现材料，不能因名字含“旧”而删除。

## 复现入口

从仓库根目录运行（先依 [ENVIRONMENT.md](../ENVIRONMENT.md) 安装当前环境；历史锁文件不应混装）：

```bash
# 方案一上游：先查看实际参数，按 protocol.json 的配置运行
PYTHONPATH=.:src python scripts/evaluate_screened_pde.py --help
# 方案一下游：按各案例 protocol.json 运行；此命令显示参数而不启动训练
PYTHONPATH=.:src python scripts/eqgpt/fast_reward_case.py --help
# 方案二上游
PYTHONPATH=.:src python scripts/run_upstream_811.py
# 方案二下游：从已保存权重/结果恢复时会校验并复用
PYTHONPATH=.:src python scripts/eqgpt/run_expanded_all_cases.py --device mps
# 方案三：只查看已完成结果；重新运行需要显式 --execute-reviewed-protocol
PYTHONPATH=.:src python scripts/eqgpt/run_study3.py --phase plan
```

`--help`是参数查看，不代表已经重跑或验证整套结果。完整下游运行会训练、搜索，常规结果查看不需要运行。已有权重的下载与使用见各Release和 `scripts/eqgpt/README_权重.md`、`experiments/expanded_downstream_80_v1/README.md`。
