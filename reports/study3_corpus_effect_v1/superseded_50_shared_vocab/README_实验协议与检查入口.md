# 第三套实验：语料扩大对 PDE 发现的影响

当前状态：**代码与语料准备；正式预训练、候选搜索均未启动，等待用户审阅。**

本实验重新训练小语料组和大语料组，不直接拿旧权重充当新基线。前两套实验的代码、配置、权重、语料和结果均保持原样。新规则在第三套内同时用于两组；历史结果仍标为旧规则结果，不追溯改写。

## 研究问题与结论边界

1. 在相同架构、词表、训练规则和搜索预算下，扩大语料改善还是削弱 PDE 结构发现？
2. 差异发生在生成、解析/数值评估、reward 排序/去重、累计候选保留，还是 continuation 后的生成分布？

采用一个配对种子525、八个固定案例。第一轮200次反映预训练后的生成；三轮合计600次已经包含选择与微调反馈。机制记录能定位观察到的失败环节，不等同于通过独立干预证明唯一因果原因。“未生成”仅指固定预算内未观察到。

25 epoch 表示相同遍历次数，不表示相同更新步数、token数或FLOPs。本实验研究固定训练规则下扩大语料的实际效果，不声称固定算力的纯数据收益。暂不增加模型规模、词表扫描、额外案例、其他增强或最终系数拟合/PINN。

## 唯一主动变化：增加Transformer训练公式

两组**共用仅由小语料增强文本学习的Hard词表**，保持旧的98字节基础表和280/315/350总ID档位。词表不是分别在两组重新学习，避免“语料变化+分词规则变化”混杂。

准备时尝试大语料重学词表，发现一条原212公式在重学词表下超过50容量。该尝试已放弃，不进入正式数据。最终冻结小语料词表后，726条全部通过共同容量检查；全部212条保留，且其32条增强在大组中逐行完全相同。大语料仍可能含与旧手册重复的结构，726指来源记录，不声称726个独立结构。新增记录按既有八案例结构/高度相似排除审计处理，并在本次重新检查确切目标结构。

此设计回答**固定分词器时，扩大Transformer预训练语料的影响**；不回答同时扩大分词器训练语料的整体收益。

## 文本及增强协议

1. 使用已审计的无系数GRE结构；不引入额外LaTeX解析工具替代现有PDE语义规则。
2. 只交换顶层加法项、标量乘法因子。分子与分母不能互换，命名导数/函数原子不拆开，不改系数、导数阶数或项集合。
3. 用多重集排列编号计数/抽样，不枚举阶乘空间。不同表达不少于32种时，保留规范化原排列，再从其余表达不放回抽31种；少于32种时先保留全部，再均衡重复补32条。
4. 固定种子+源ID，使已有公式的增强不受新增公式、文件位置或处理顺序影响。
5. 结构排列完成后才附加BOS/EOS；EOS严格只在末尾。每条增强GRE由固定函数渲染成Hard文本，保留排列顺序；EqGPT/Hard按相同源ID和增强编号逐条配对。
6. 全部三档Hard及GRE的32条增强均须满足50训练容量；超长源记录从双方共同排除，不截断、不因目标表现筛选。

统一渲染指统一导数、乘法、括号等记号。无系数结构不是原带符号/带系数方程的数学等价LaTeX改写，系数在该表示中省略；本次两组/两类模型的结构输入一致。

最终最大训练长度：小组GRE19，Hard280/315/350分别32/26/23；大组GRE49，Hard分别35/33/32。全部经逐行编码还原检查。

## 机制追踪

每条候选记录原始token、停止原因、原始LaTeX、解析GRE、清理前后结构ID与结构分类、原始reward、筛选时float32 reward、当轮原始分数排名、同分候选、是否当轮入选、是否进入累计Top10，以及具体淘汰原因。

沿用现有结构分类器与去重规则，不用真实目标指导搜索。结构ID范围为加法/乘法交换及原分类器已支持的Laplacian展开，不声称识别所有数学等价式。原始重复项与清理后的结构分别记录，不把清理修复误算成原始正确生成。

逐轮记录累计Top10中每条候选的ID、结构、分数、排名、原始出生轮次对应关系，掉出Top10事件，以及实际用于微调的编码序列。按reward数值去重、Top10竞争及数值不可用均单独标记。`mechanism.json`提供逐结构时间线和第一轮/全程生成统计。

保存预训练搜索前、每轮微调后的checkpoint。搜索前checkpoint硬链接共享预训练权重；最终searched.pt硬链接第三轮checkpoint，减少重复存储。中间两轮仍保存独立权重，用于复查。

搜索全部结束后，独立执行：

- 真实目标及搜索中出现的正确有序表达的固定条件评分。每个表达重新建立独立评估器，结果不反馈到搜索。
- 各checkpoint下目标固定表达、已生成正确表达以及Hard原始正确文本的teacher-forced对数概率。
- 探针不更新GPT或MLP权重。检查前后权重哈希一致。

reward由数值数据和具体有序表达决定，不直接由GPT权重决定；作者评分将第一项固定为系数基准，同结构不同项顺序的reward可能不同。对数概率是原始softmax，不是EqGPT包含SAT和80/20混合的实际采样概率，仅用于同一arm、同一表达的前后比较。概率变化不直接作跨分词器数值比较。
