# 第三套实验：语料扩大对 PDE 发现的影响

当前状态：**正式小语料与大语料运行均已完成；64个搜索组、38,400个候选通过完整性核验。**

本实验重新训练小语料组和大语料组，不直接拿旧权重充当新基线。前两套实验的代码、配置、权重、语料和结果均保持原样。新规则在第三套内同时用于两组；历史结果仍标为旧规则结果，不追溯改写。

## 研究问题与结论边界

1. 在相同架构、词表容量、训练规则和搜索预算下，扩大语料改善还是削弱 PDE 结构发现？
2. 差异发生在生成、解析/数值评估、reward 排序/去重、累计候选保留，还是 continuation 后的生成分布？

采用一个配对种子525、八个固定案例。第一轮200次反映预训练后的生成；三轮合计600次已经包含选择与微调反馈。机制记录能定位观察到的失败环节，不等同于通过独立干预证明唯一因果原因。“未生成”仅指固定预算内未观察到。

25 epoch 表示相同遍历次数，不表示相同更新步数、token数或FLOPs。本实验研究固定训练规则下扩大语料的实际效果，不声称固定算力的纯数据收益；本次同时允许Hard词表随语料重新学习。暂不增加模型规模、词表扫描、额外案例、其他增强或最终系数拟合/PINN。

## 词表独立学习：用户最终方案

小组用212条未增强、GRE统一渲染LaTeX学习Hard词表；大组用1,100条未增强、GRE统一渲染LaTeX独立学习Hard词表。每条源记录在词表训练语料中出现一次，不使用32倍增强版本。两组保留相同98字节基础表与280/315/350总ID容量，但token内容、ID含义与合并规则分别学习，不复制共享词表。

Transformer分别使用各自的32倍增强语料。原212条公式及其增强结构/LaTeX在大组中逐行完全相同；同一文本在两个独立词表下可以切分成不同token序列。相同初始化种子与容量使初始数值张量一致，但不同token行的语义不要求一致。

此设计研究扩大语料对“Hard词表学习+Transformer预训练”整套流程的影响。EqGPT固定词表不变；Hard词表变化是用户要求的实验因素。因此Hard结果变化不能全部归因于Transformer预训练语料，生成/选择追踪仍可定位变化发生的环节。

未增强源公式先按GRE容量筛选，再独立训练各组词表并检查全部增强序列。如果发生Hard超长，则共同排除该来源并重学该组词表，全部原212条必须保留。当前两组无需额外Hard排除。旧50容量共享词表版本归档在`superseded_50_shared_vocab/`，其四轮检查已失效，不用于当前运行。

## 文本及增强协议

1. 使用已审计的无系数GRE结构；不引入额外LaTeX解析工具替代现有PDE语义规则。
2. 只交换顶层加法项、标量乘法因子。分子与分母不能互换，命名导数/函数原子不拆开，不改系数、导数阶数或项集合。
3. 用多重集排列编号计数/抽样，不枚举阶乘空间。不同表达不少于32种时，保留规范化原排列，再从其余表达不放回抽31种；少于32种时先保留全部，再均衡重复补32条。
4. 固定种子+源ID，使已有公式的增强不受新增公式、文件位置或处理顺序影响。
5. 结构排列完成后才附加BOS/EOS；EOS严格只在末尾。每条增强GRE由固定函数渲染成Hard文本，保留排列顺序；EqGPT/Hard按相同源ID和增强编号逐条配对。
6. 全部三档Hard及GRE的32条增强均须满足60训练容量；超长源记录从双方共同排除，不截断、不因目标表现筛选。

统一渲染指统一导数、乘法、括号等记号。无系数结构不是原带符号/带系数方程的数学等价LaTeX改写，系数在该表示中省略；本次两组/两类模型的结构输入一致。

最终最大训练长度：小组 eqgpt_reference=19, ast_bpe_280=32, ast_bpe_315=29, ast_bpe_350=24；大组 eqgpt_reference=59, ast_bpe_280=51, ast_bpe_315=36, ast_bpe_350=35。全部经逐行编码还原检查。

## 机制追踪

每条候选记录原始token、停止原因、原始LaTeX、解析GRE、清理前后结构ID与结构分类、原始reward、筛选时float32 reward、当轮原始分数排名、同分候选、是否当轮入选、是否进入累计Top10，以及具体淘汰原因。

沿用现有结构分类器与去重规则，不用真实目标指导搜索。结构ID范围为加法/乘法交换及原分类器已支持的Laplacian展开，不声称识别所有数学等价式。原始重复项与清理后的结构分别记录，不把清理修复误算成原始正确生成。

逐轮记录累计Top10中每条候选的ID、结构、分数、排名、原始出生轮次对应关系，掉出Top10事件，以及实际用于微调的编码序列。按reward数值去重、Top10竞争及数值不可用均单独标记。`mechanism.json`提供逐结构时间线和第一轮/全程生成统计。

保存预训练搜索前、每轮微调后的checkpoint。搜索前checkpoint硬链接共享预训练权重；最终searched.pt硬链接第三轮checkpoint，减少重复存储。中间两轮仍保存独立权重，用于复查。

搜索全部结束后，独立执行：

- 真实目标及搜索中出现的正确有序表达的固定条件评分。每个表达重新建立独立评估器，结果不反馈到搜索。
- 各checkpoint下目标固定表达、已生成正确表达以及Hard原始正确文本的teacher-forced对数概率。
- 探针不更新GPT或MLP权重。检查前后权重哈希一致。

reward由数值数据和具体有序表达决定，不直接由GPT权重决定；作者评分将第一项固定为系数基准，同结构不同项顺序的reward可能不同。对数概率是原始softmax，不是EqGPT包含SAT和80/20混合的实际采样概率，仅用于同一arm、同一表达的前后比较。概率变化不直接作跨分词器数值比较。


代码审阅后若有修改，重新完成相应检查并刷新四轮记录，不能沿用旧哈希。共享预训练可复用其已有断点机制；搜索遇到不完整目录会明确停止，不自动删除或覆盖后重跑。完整搜索通过文件哈希验证后可跳过。

检查结果见`checks_4rounds.json`及对应日志。模拟搜索测试只使用模拟评分/模拟参数变更，不执行真实优化器步骤；真实集成检查仅前向计算及固定输入数值评分，没有候选采样、微调、预训练或MLP拟合。


## 第五轮补充复核

最新完整回归89项通过。除前述四轮内容外，再核实每条源公式的32条增强具有规定的不同表达数量及均衡重复；每档大小语料Hard的backend确实不同；两个词表训练清单都只含本组未增强文本。

新增整体汇总按cohort和arm分别计算八方程Top1/Top10、完整正确生成覆盖、正确候选可评分覆盖、已生成可评分正确式条件下的最终Top10选择成功率、候选有效率、第一轮完整正确生成比例及Top1冗余数。截断但恰有目标项的前缀不计完整生成成功，仍保留作者清理后发现结果供另行比较。不同arm及同一方程的600次候选不作为独立方程重复。

按当前交换不变结构ID规则（非任意数学等价判定），小组212条来源记录对应185种结构，大组1100条对应1073种结构；两组的27条重复富余来自保留的原始手册。追加语料确实增加了结构覆盖，但“语料数量”“类型/分布”“Hard词表”及实际更新量同时变化，不能把最终差异解释为仅由条数改变。

结论范围：这批语料扩大方案（Hard分别重学词表、相同25epoch规则、固定搜索预算）对八个固定PDE案例的整体结构发现表现。单个配对种子不能支撑统计稳定的普遍规律，当前实验不测最终系数恢复，也不推断所有PDE的整体能力。机制日志定位观察到的环节，不证明唯一因果机制。
