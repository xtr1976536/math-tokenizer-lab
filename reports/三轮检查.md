# 仓库发布三轮检查

## 第一轮：内容与来源

- 上游主实验有 16 条结果，即四种分词器 × 四种划分；补充词表扫描只包含 Hard AST-BPE。
- 下游有八个案例，共 24 个 Hard AST-BPE 实验和 8 个缩小版 EqGPT GRE 对照实验。每个实验保留训练记录、候选搜索轨迹和结构分类；每个案例保留共享 surrogate 缓存与筛选后的运行日志。
- 上游 benchmark 包含 1500 条 PDE，来自 490 个来源组，语法复杂度为 450/600/450；其余 55,644 条公式保持原记录。下游八案例数据及 EqGPT 原始结构工作簿齐全。
- 参考资料包括 AST-BPE 原论文、EqGPT 原论文、用户提供的《EQGPT_v8_中文最新版》及本项目中文报告四份 PDF；原仓库链接和许可见 `参考资料/README.md`。

## 第二轮：代码与实验协议

- Qwen2.5、Llama 3、`o200k_base` 和 Hard AST-BPE 的加载入口均完成一次真实编码与解码；EqGPT 原作者文件通过 SHA-256 来源检查。
- 下游实际协议为 3 层、25 epoch、种子 525、3 轮 × 200 次候选、每轮继续训练 2 epoch；共享 5 层 × 宽 50 的 MLP surrogate，保留最小二乘 reward，不执行最终 PINN。README 已明确区别于原论文的 6 层和较大预算。
- 上游和下游的展示结果、日志仅保留当前四分词器及 Hard/GRE 两类实验的行；旧 soft 方法的结果文件与专用代码入口已移除。原作者第三方源码按其原样保存。
- 大型 Transformer 权重未进入 GitHub。单独的本地 Hard 八案例 ZIP 已在上一轮生成并校验；本仓库提供模型训练和搜索日志、词表、数据及源码。

## 第三轮：可视化与发布

- 网页使用冻结的 280/315/350-ID Hard 词表、真实合并规则和原生前端结构边界。随机抽取的 100 条 benchmark 公式 × 3 个词表，浏览器最终 token ID 与 Python 一致，合计 300/300；自定义 LaTeX 示例的结构区间也与原生实现一致。
- 在桌面 1440×900 和手机 390×844 视口通过 `file://` 实际打开；搜索、选择、切换词表、单步与播放均可操作，无控制台异常或横向溢出。
- 直接打开 `docs/index.html` 即可离线浏览全部 1500 条 benchmark 公式，无需开发服务器。
- 私有仓库的 GitHub Pages 启用请求返回 HTTP 422：当前账号套餐不支持该私有仓库的 Pages。因此本轮网页已入库且可离线使用，尚无 GitHub Pages 网址；未改变仓库私有状态。

可重新执行 `python scripts/检查仓库.py` 做内容审计。这里的八案例是**已知 PDE 回收实验**；真实未知方程 benchmark 尚未定稿，不在本仓库。
