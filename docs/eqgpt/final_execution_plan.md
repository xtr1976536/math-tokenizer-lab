# EqGPT 数学分词主实验：最终执行计划

更新：2026-10-16。依据用户确认的五项选择与两轮训练方案制定。
本文件覆盖本轮主实验；容量、语料、自动词表与 SAT 改造实验暂缓。

## 1. 研究问题与四组系统

研究问题一：同一 LaTeX、词表容量与主干下，数学分词器是否优于普通 BPE？
研究问题二：数学分词器支持的无 SAT 系统能否超过原 EqGPT 的 GRE＋SAT 系统？

| 系统 | 模型训练表示 | 词表 | 生成端 |
|---|---|---|---|
| 原 EqGPT 参照 | 作者 GRE | 原作者 57-ID 词表 | 原作者 SAT |
| 普通 BPE 对照 | 同一份 LaTeX | 独立数学训练分区，1,024 总 ID | 无 SAT |
| 标准 AST-BPE | 同一份 LaTeX | 同一分区，1,024 总 ID | 无 SAT |
| 软 AST-BPE | 同一份 LaTeX | 同一分区，1,024 总 ID | 无 SAT |

三个 LaTeX 系统用于分词器比较；与原 EqGPT 的比较用于系统能力比较。
不把表示、容量与 SAT 同时变化带来的全部收益归因于分词器。
“无人工规则”在本轮精确指生成阶段不应用 SAT 语法／变量掩码；表示转换、
数值求导与奖励仍包含公开的人工设计，不能称整个系统完全没有人类知识。

## 2. 分词器语料与冻结

1. 采用现有 benchmark 的固定广领域训练分区，原始候选为 36,615 条。
2. 保留验证／测试分区；筛除下游目标、可识别等价结构及来源不合要求的记录，记录每条排除理由。
3. 对可能与目标相关、但等价性无法可靠判定的公式隔离审查，不作“已经证明无重合”的默认处理。
4. 固定最终 ID 清单、来源、处理记录和 SHA-256；同一清单训练普通 BPE、硬 AST-BPE、软 AST-BPE。
5. 总 ID 固定为 1,024，含 PAD／EOS／BOS 与所有基础符号、原子、合并片段。不得用无效占位 ID 伪造达到容量。
6. 原算法和既定结构权重沿用，不能用下游测试结果再调分词器。
7. 训练完成后冻结。所有 PDE 案例、训练种子和两轮训练复用同一套检查点。
8. 六层 Transformer 不在数学 benchmark 上预训练；它仅使用作者手册公式训练。

已有检查点须先核对训练清单和源码哈希，符合条件可复用；不符合则在
本轮固定清单上按相同算法重训。尚不能把旧 GRE 词表包或旧 LaTeX smoke
作为这一阶段已经完成的证据。

## 3. 模型训练公式与表示

1. 原始内容为作者发布的 221 行 PDE 结构。发现某一目标时，排除目标及其已识别等价结构。
2. 由统一的数据增强过程产生加法项和乘法因子排列，按作者 32 倍设置，四组共享同一份数学内容与顺序。
3. 原 EqGPT 使用 GRE，三个新系统使用同一固定、可追溯的 LaTeX 转换。特殊标记独立记录。
4. 检查全部 51 个基本项、221 行公式及增强结果的数学含义往返，不能仅检查字符串可解码。
5. 公式仍为作者的待估计系数结构；系数由后续回归和 PINN 求得，不凭空添加训练系数。
6. 所有方法使用同一组完整公式，不能按不同 tokenizer 过滤或截断训练样本。
7. 模型选择的验证组按原始结构划分，增强排列和重复结构不跨分区。

## 4. 主干与必要适配

- 使用作者原始 GPT 类：6 层、8 头、768 维隐藏表示、2048 维前馈、每头 K/V 为 64。
- 不加载预训练 GPT-2 参数；所有神经网络参数从零初始化、全量训练。
- 原始源码逐字节保留，语法、路径、目标排除和优化器错绑等已批准问题仅在包装层修复并记录。
- 仅适配词表相关输入嵌入与独立输出投影。三个 LaTeX 模型均为 1,024×768 输入嵌入和对应的输出层。
- 根据共同训练样本检查上下文容量；必要的容量扩展对四组一致，且独立保留作者 GRE 生成长度条件。
- 相同种子、相同形状的主干参数从相同初值开始；记录完整及主干哈希与总参数量。
- 不改注意力、激活、归一化、残差或前馈结构来补齐参数量。

## 5. 两轮模型训练

### 第一轮：统一配置

四组均为 Adam、LR1e-4、100 epoch、有效 batch128 条原始公式、梯度裁剪1、
常数学习率。这里 epoch 指遍历同一原始增强公式列表，不指遍历各自数量
不同的 token 包。记录实际 token 数、padding、更新步数和运行成本。

### 第二轮：相同选择机会，各自选择超参数

- 借鉴 Lotz 的共同原始数据、pilot 检查与成本报告思路，不照搬其大语料只训练一轮的数值设置。
- 共同 pilot 排除全部最终测试目标／等价结构；其余手册公式按原始结构固定留出约10%验证。
- 四种方法共用三个 LR 候选3e-5、1e-4、3e-4；各轨迹从零训练到300 epoch，在100与300处评分，共六个候选设置。
- 优化器、有效 batch、常数学习率形式和梯度裁剪保持一致；100处不重启优化器。
- 验证使用每个唯一原始公式的完整序列 NLL，只在同一个方法内部比较候选，不跨不同 tokenizer 用原始 CE／困惑度排名。
- 禁止用测试目标的数值观测、奖励、恢复率或最终结果选择学习率、epoch 或词表。
- 每个方法全局选一组超参数并冻结，所有正式 PDE 案例／种子共用，不逐个目标重新调参。
- 选择后重新初始化，按每个案例允许的全部手册训练公式重训；仍排除该案例目标。
- 调参种子524，最终种子525／526／527。调参成本和最终拟合成本分开记录。
- 失败候选保留，无单独补试；若以后扩大候选范围，所有方法一起扩大。

第二轮允许最终 LR／epoch 不同，但不声称等次数调参就是等 FLOPs。
两轮结果分别报告，不合并为同一训练条件；采样、奖励和 PINN 不参加本次调参。

## 6. 生成与发现循环

LaTeX 三组：从 BOS 直接按完整输出分布自回归采样；不枚举作者 GRE 项，
不设置项／运算符或变量掩码，不采用生成时语法约束。使用共同 temperature1，
EOS／统一长度与字节预算用于结束生成，不用于数学有效性筛选。

每个优化周期固定400次生成尝试，共5周期；每次尝试原样保存。原 EqGPT
保留作者 SAT 与80%模型采样／20%合法动作随机探索。

生成后的共同数值处理：

1. 完整解码并解析表达式；记录截断、解码／语法失败、不支持的项和变量不适用等类别。
2. 可支持的 LaTeX 转为作者评估器接收的结构，原 EqGPT 的 GRE 直接进入相同数值阶段。
3. 共用同一观测数据、噪声、替代网络、元数据和导数计算，调用作者奖励与系数回归。
4. 采用同一作者候选筛选规则和已批准的共同异常处理。有限数值奖励以外的候选保留失败记录，不补采样或用真值修复。
5. 保留至多10个候选，按作者规则合并前轮候选；若不足10个，使用实际数量。若为0，跳过该轮更新，继续下一轮固定400次。
6. 继续训练仍为5 epoch、Adam、LR1e-5；此参数不加入本次搜索。生成模型必须与其优化器正确绑定。
7. 最后用作者 PINN 优化前3候选，保留可用候选不足或数值失败的状态，三组重置到相同初始替代网络。

不得生成直到凑齐400个合法式子。不得因为无 SAT 可用率低而自动加回 SAT。

## 7. 案例、重复与规模

主案例沿用已核对的11个：KdV、Burgers、Wave、Chaffee–Infante、Klein–Gordon、
Allen–Cahn、Convection–diffusion、PDE divide、Eq.6.2.12、PDE compound、圆盘 Poisson。
前10个使用10,000观测点，圆盘使用30,000；主比较先使用无噪声。

- 每轮：11案例×4系统×3种子＝132个最终训练／发现配置。
- 两轮合计：最多264个最终配置结果。
- 共同 pilot：4系统×3LR＝12条独立训练轨迹，在100／300处检查，共24个候选评分。
- 如果第二轮选中与第一轮完全相同的训练设置，复用合格检查点和同一确定设置的结果，标明重用；不当作新的独立重复。
- 每个案例／种子的观测和替代网络可在四系统及两轮间复用固定快照，不能随机重新抽样后仍称配对。

EITech、高维与真实水波案例的未对齐问题不加入本次主结果。云端完整耗时
需由所选机器短测后估算，不能用缩小预算的 CPU smoke 直接外推为正式耗时。

## 8. 指标与报告

主结果为正确 PDE 结构恢复率；同时报告带冗余项恢复、Top-10恢复、每轮
奖励、可对齐时的系数误差、PINN数值失败，以及训练和端到端发现时间。
生成端分别报告支持语法的解析通过、可数值评估率和各种失败计数；不得把
“作者评估器支持”混称为所有数学意义上的合法性。

以400次尝试为每轮生成率分母；以全部案例／种子为发现成功率分母，保留
没有可用候选的运行。系数误差报告其可评估数量，不只给成功子集均值。
按案例／训练种子汇总配对差异，400个候选不作为400个独立训练重复。
三个种子能量化部分训练波动，不能承诺已经消除全部不确定性。

分别给出第一轮统一训练表、第二轮验证选择表、两轮选择参数与实际成本表。
不把原 EqGPT 系统差异全部解释为 tokenizer 因果效应。

## 9. 审查、交付与停止条件

运行正式任务前至少四轮检查：

1. 数据：源版本、目标／等价式排除、数学含义往返、增强分组、独立数学训练语料、词表冻结。
2. 模型与优化：作者文件哈希、允许的适配、参数量、初值、全部参数可训练、梯度／优化器绑定、保存重载。
3. 生成与数值：无SAT、400次、不补采样、非法输出记录、奖励／候选选择／PINN一致性、共同数据和快照。
4. 可复现性：重复运行、数据与模型哈希、候选完整记录、验证不接触测试、解压后的云端包独立smoke。

每一轮附可执行检查和实际结果，失败先修复，不把“能够执行”当作效果有效。
本地只做烟雾和校准，正式实验在用户选择的GPU平台运行；不自动购卡、上传或付费。
最终交付代码、冻结词表／数据清单、运行包、环境、审查报告、原始结果和中文分析。

若无SAT的可评估候选过少，先如实完成并分析本主实验，再依据失败类型
讨论子词适配SAT。启用条件、规则及新实验单独确定，保留原无SAT结果。
当前不运行57-ID、512／2048、PDE子集、作者语料词表、自动词表或SAT消融。
