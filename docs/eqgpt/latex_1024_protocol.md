# 后续实验：LaTeX、1,024-ID、无 SAT 生成

确认日期：2026-10-16。顺序：先完成 GRE 57-ID 实验，再实施本实验。
当前只记录研究计划，未实现或运行。

## 研究问题

1. 在同一 LaTeX 表示、相同训练公式和模型下，数学 AST 分词能否改善无规则生成与 PDE 发现？
2. LaTeX 生成系统在取消 SAT 后，能否超过作者原 EqGPT 系统？

第一个问题用同条件 tokenizer 对照回答；第二个问题属于系统比较。
LaTeX、词表容量、生成策略同时变化时，不能把相对原 EqGPT 的全部差异
单独归因于分词器，也不能预先认定 1,024 个 ID 已达到最佳容量。

## 比较方案

- 保留作者原 GRE／57-ID／SAT 系统作为参照。
- LaTeX／1,024-ID／无 SAT：普通 BPE、标准 AST-BPE、软 AST-BPE。
- 三个 LaTeX 系统使用同一作者六层 Transformer，从零训练，特殊 ID 全部计入容量。
- 第一轮沿用同一批作者公式及目标排除规则；不引入完整数学 benchmark 作为额外训练数据。
- GRE 到 LaTeX 的转换采用固定、可追溯的表示，保留每式与作者结构的对应关系。
- 三个 LaTeX 系统接收完全相同的训练字符串、增强结果、顺序和训练协议。

## 无 SAT 的含义

- 模型直接自回归采样 LaTeX，不枚举作者完整 GRE 动作。
- 不应用项／运算符交替掩码，也不应用问题变量掩码。
- 不在生成过程中用语法、AST 或变量规则剔除候选 token。
- AST-BPE 的分词约束属于 tokenizer 本身；不能把它扩展成额外的生成掩码。
- 原 SAT 的“合法科学动作中 20% 均匀探索”不直接迁移到子词；无 SAT 各组使用同一声明的普通采样设置。
- EOS 与共同长度／计算上限用于结束生成；它们不作为数学正确性约束。

每轮固定 **400 次生成尝试**，不能重试直到得到 400 个合法式子。
非法、截断、变量不适用、作者评估器不支持、数值失败均保留并计入对应统计。
支持表达式的解析与评估统一，不引入依赖目标答案的修复或筛选。
需要明确不足 10 个可用候选时的统一继续训练规则，不能隐式追加采样。

## 后续数值阶段

LaTeX 解码后经共同解析器转换为作者评估器支持的 PDE 项结构，再调用
相同的替代网络、元数据、奖励、候选筛选、继续训练和 PINN 系数优化。
解析器是表示适配接口，需验证往返和数学含义；作者不支持的新表达式
应报告为不可评估，不为单个模型扩展奖励或导数实现。

## 评价与审查

报告语法／评估可用率、结构恢复、top-10 恢复、系数误差、数值失败、
训练和端到端发现时间，以及实际 token 工作量。所有 400 次尝试保留记录。
对同条件的分词器比较使用配对数据与种子。实施前完成至少四轮一致性审查。

两轮结果结合解释：GRE／57-ID 用于控制容量下的编码方式比较；
LaTeX／1,024-ID／无 SAT 用于测试数学源码建模与减少人工生成规则的能力。
