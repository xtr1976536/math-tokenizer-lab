# EqGPT 论文原版完整代码

本目录保存 [EqGPT 原作者仓库](https://github.com/woshixuhao/EqGPT) 固定提交 `dc35fc0ac860ff224293f01d2a62204042095127` 的源码。`code/` 中包含原训练、搜索、surrogate、reward 以及 **`PINN_optimization.py`** 等完整论文路径；原始文件保持字节不变，来源哈希见 `provenance.json`，许可见 `LICENSE`。

本目录不是本项目的缩小版实验。缩小版入口在 `scripts/eqgpt/fast_reward_case.py` 和 `src/math_tokenizer/eqgpt/`；它把 Transformer 改为 3 层、训练 25 epoch、搜索 3×200 次，保留 reward，但不执行最终 PINN。论文原版源码中的默认参数和完整 PINN 流程不应与这批快速实验的结果混用。

八案例原始数据统一放在 [`data/cases/`](../data/cases/)，公式表放在 `data/formulas/eqgpt/`。本目录的 `data` 和 `code/PDE_dataset_0725.xlsx` 保留相对链接，供原版代码按原路径读取；文件内容和来源哈希不变。数据、MLP 缓存和权重的具体路径见 [数据说明](../data/README.md)。
