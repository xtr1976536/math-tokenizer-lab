# v7：先修复归因和公平性，再检验新机制

旧v6语料、模型、全部分数保持作对照。v6测试已经暴露，本轮不称其为未见测试，不使用其分数选择新的参数。模型候选只用已有fit、reward和dev；新增固定许可2020年前论文先完成来源/宏保真/语法/重复与分类审查，封存后不得读取模型分数，直到配置冻结。

执行顺序：最近邻同先验基线和资源匹配→AST机制消融与完整路径词表优化→RL延迟收益/策略迁移及同reward控制→独立本征验证→多来源/领域诊断→新封存测试及排名。每个步骤记录成功、失败和未完成事项，不以实现一个环节宣称所有审稿问题解决。

第一阶段公共信息：每个场景复用v6同fit ID、512式reward和同dev。词法原子从fit取得；所有同原子方法共享相同原子列表和预算，完整256字节回退计入总ID。官方BPE分别在fit及fit+reward训练，原子BPE/PathPiece也提供同范围版本；自研及简单greedy使用同reward选择。所有候选给予同dev访问、记录搜索次数、训练时间与预算。新增测试不进入原子学习、reward、选择或校准。

AST探索：以完整公式上的实际受约束最短路径替代损失，而非词条孤立分词代理，进行词表删除/增补；候选仅由fit提出，选择损失在同reward测量。探索按来源论文/领域等权与尾部风险加权的取舍。它借鉴Unigram词表剪枝、语法压缩和风险控制，不把这些已有概念本身称为首创。逐层禁用词法、树约束、词表结构化及风险目标，区分算法与原生实现收益。

RL探索：完整未来合并回报、可共享策略/价值估计、跨训练子集迁移；与同候选/同奖励frequency、greedy和等计算search对比。若局部期望梯度不胜greedy，如实报告。离线指部署前学习而非logged-data offline RL。奖励不只压缩：概率编码/罕见词条、独立结构、词法和布局稳定性都记录，禁止只挑有利指标。

本征评分沿用v6定义，并加独立边界/作用域及编辑局部性探针，检查字符/整式记忆等退化策略。任何新领域指标都标为本研究定义，不能假称普遍认可。概率平滑做预声明敏感性；已知和未知命令、深树、长输入等分别统计。无需下游模型。

本轮初始预算1024、2048；开发试验从小子集顺序扩大到完整fit/dev。正式配置及主要比较在新test首次评分前冻结；相同全部原始输入、相同校准、原文无损门槛和7次交错计时。结果以原始差幅、Pareto及论文聚类CI为主，综合榜不代替因果证据。旧大模型官方tokenizer可直接在新test评测，不改词表。

人工结构双审、外部独立专家评估、多硬件实测不能由助手自动冒充。本轮可建立标注材料、验证反例及现有机器上的多进程重复证据；未取得的证据明确留为缺口。
